# Trabajo Práctico Individual Nº 1 - Computación III
## Cátedra Wischñevsky - 2do. cuatrimestre 2026

En este trabajo se buscó realizar un Curriculum Vitae propio en HTML5 usando etiquetas semánticas para la diagramación de una página, además del uso de diferentes selectores CSS y Flexbox para dar propiedades a dichas etiquetas.

## Componentes de la página (Curriculum Vitae).
Características de Head
* Elaborado en idioma español
* Linkeado a un archivo .css y fuentes obtenidas desde Google Fonts
* Agregado de un favicon.

Elementos usados en la estructura Body:
* Header con sección de navegación (Inicio, Editorial, Afiches y Fotografía)
* Presentación personal acompañada con una foto de perfil
* Secciones destinadas a "Formación Académica", "Aptitudes Informáticas", "Competencias Laborales" y "Proyectos Destacados" donde se usaron etiquetas como section, div, article y figure.
* Footer con enlaces a otras redes sociales acompañados de legales e información de la cátedra.

## Información técnica
* Programa editor de códigos usado: Visual Code.
* Github para compartirlo en Internet.
* Inspector del navegador Mozilla Firefox para acompañar el diseño y organización de la página.
* Resolución de pantalla durante el proceso: 1920x1080 px.

## Información sobre el diseño
* Tipografías usadas: Marcellus y Quicksand, ambas disponibles en Google Fonts para uso gratuito.
* Paleta cromática general gira en torno a los colores análogos del identificado como "purple" de las opciones dadas por VSCode y "cadetblue" fue elegido para diferenciar el apartado de "Proyectos destacados".
* Las imágenes usadas son de producción propia.
